# Mes Finances

Application de gestion de finances personnelles pensée pour l'iPhone, en un seul fichier (`index.html`), sans installation ni serveur.

## Utilisation

- **Site** : https://noethibaud-byte.github.io/claude/gestion-finances/ (à ajouter à l'écran d'accueil depuis Safari : Partager → Sur l'écran d'accueil). Les données restent sur le téléphone.
- **Version Claude** : les données sont enregistrées dans le compte Claude et les comptes Finary se mettent à jour automatiquement.

## Fonctionnalités

- **Accueil** : solde, revenus, dépenses et taux d'épargne du mois, reste à dépenser, patrimoine par groupe (comptes courants, épargne, placements), bilan du mois, dernières opérations, graphiques.
- **Opérations** : dépenses, revenus et virements, regroupés par jour ; recherche sur tous les mois ; filtre par catégorie ; écran pour classer rapidement les opérations « À classer » en créant des règles au passage.
- **Import de relevés** : PDF BoursoBank ou CSV, avec aperçu, classement automatique des enseignes courantes, reconnaissance des virements entre vos propres comptes et doublons ignorés.
- **Budgets** : plafond mensuel par catégorie, reste à dépenser et montant disponible par jour, rythme de dépense, budgets proposés d'après la moyenne des 3 derniers mois.
- **Bilan du mois** : comparaison avec le mois précédent, plus grosses dépenses, enseignes les plus fréquentes, paiements réguliers détectés.
- **Objectifs d'épargne** : montant cible, échéance et effort mensuel conseillé.
- **Finary** : comptes et soldes (version Claude), transmis au site par un code à copier-coller.
- **Sécurité** : code à 4 chiffres demandé à l'ouverture.
- **Sauvegarde** : rappel mensuel sur le site, export vers Fichiers / iCloud Drive, restauration.
- Changement de mois en glissant le doigt à gauche ou à droite.
